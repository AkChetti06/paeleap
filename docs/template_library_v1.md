# Paeleap 图片模板库 V1

版本：1.0 · 2026-10-27 · 状态：离线提示词模板，尚未进行 AI 图片生成或效果验证。

## 这三种方向从哪里来

已回查项目聊天《Paeleap C1 internship》《Week 1》，以及 2026-10-14《最终20篇视觉风格分类报告》和配套 P1–P20 视觉标签。
原报告将样本按风景区（7）、文博场所（7）、研学场所（6）组织，强调图片的信息任务，**没有将三种固定美学风格定为研究结论**。
下面三套是本次从样本转译的产品模板 V1，待导师反馈后调整。不能把景区类型、文本风格与图片风格混为一谈。

原始报告：../outputs/01a12e9f-8427-7e62-b8e2-38dc79936eca/Paeleap_C1_最终20篇视觉风格分类报告_2026-10-14.html（项目资料，非本仓库文件）。
引用的图页观察来自已存档研究；本次没有重新核实笔记互动数据、活动日期或景区服务。

## 简单使用流程

1. 先生成文案；景点、推广重点、目的、人群和当前选中的文案自动带入图片页。
2. 选择“自然照片 / 水墨海报 / 旅行拼贴”，主体默认沿用文案重点。
3. 选择感觉和图片尺寸；光线、色彩、质感和构图由模板自动组合。
4. 如有照片或特别想法，展开一个选填区域。上传景区照片后自动作为结构参考；无照片时仅为文字概念方案。
5. 右侧显示通俗的画面说明，继续到预览可查看文案与上传原图。原图不会自动风格化。
6. JSON、完整提示词和研究资料保留在仓库中供开发/导师查阅，不放在用户操作流程里。


## 自然实景感 / Natural scene

**用途**：突出景点本身与现场细节，适合风景、建筑和空间介绍。

| 模板要素 | 规则 |
|---|---|
| 色彩 | 自然低饱和，保留主体原有颜色 |
| 光线 | 柔和自然光，不改变建筑和地形 |
| 构图 | 环境全景与细节有层次，单一主角，避免过度修饰 |
| 质感 | 写实摄影感；这是概念画面，不冒充实拍 |
| 可替换字段 | 景点、文案主体、可用事实、目标人群、宣传目的、构图、比例、光线、人物、留白、处理强度方向 |

**研究依据与设计延伸**：从普通现场照片、空间与讲解关系的研究归纳为生成方向；不是原报告已命名的美学类别。

- [P4 · 莫干山真实游记](https://www.rednote.com/discovery/item/6ab45604000000001403015a)：p1–12：石路、建筑和树木的连续现场照片，无封面大字；借鉴：保留普通游客视角；体力和交通取舍交给文字。
- [P11 · 浙博讲解体验](https://www.rednote.com/discovery/item/6ac4e3b3000000001801b9c1)：p1–3：讲解员面对观众与展柜；p5：馆外现场；借鉴：人物和观众同框能表现讲解正在发生；正文可更短。
- [P12 · 湿地博物馆亲子](https://www.rednote.com/discovery/item/68b1be5b000000001b036397)：图集：建筑、环幕、生态装置及临展横幅；借鉴：空间尺度和互动环境有吸引力，需分清现场看点与泛赞美。

## 人文故事海报 / Cultural story poster

**用途**：突出建筑、文化物件和一个主题，适合文化科普与打卡封面。

| 模板要素 | 规则 |
|---|---|
| 色彩 | 米白、墨绿、赭色点缀，物件本色优先 |
| 光线 | 主体清晰，背景柔和，细节可辨认 |
| 构图 | 一个主视觉，背景退后，留出标题区域；装饰不遮挡主体 |
| 质感 | 纸感与轻水墨边缘；不重画真实物件上的纹饰或文字 |
| 可替换字段 | 景点、文案主体、可用事实、目标人群、宣传目的、构图、比例、光线、人物、留白、处理强度方向 |

**研究依据与设计延伸**：文化主题与物件突出来自研究；纸感、水墨边框和人物合成来自导师2026-10-27示例，属于本次设计延伸。

- [P7 · 课本里的绍兴](https://www.rednote.com/discovery/item/6ab9196b000000001c00cd7e)：p1–18：课文相关地点、街景、角色与食物交替出现；借鉴：以文学主题组织地点，区别于单纯摄影打卡。
- [P8 · 国博必看清单](https://www.rednote.com/discovery/item/6962941f000000002202048e)：p1：展品实景上叠大字；p3–14：一张图突出一件或一组文物；借鉴：把选择负担变成可扫读清单，标注保持简短。
- [P10 · 浙博四兽首临展](https://www.rednote.com/discovery/item/6a72e7e100000000280070ae)：p1：兽首拼贴、展名和日期；p2：四件展品；p9：平面图；借鉴：先说明这是哪场展，再从展品与空间补足预期。

## 体验步骤拼贴 / Experience storyboard

**用途**：表现先看什么、再观察什么，适合体验、任务和研学内容。

| 模板要素 | 规则 |
|---|---|
| 色彩 | 统一暖白底，少量明亮色块，避免每格不同滤镜 |
| 光线 | 各格光线与色温一致，动作与材料清楚 |
| 构图 | 三格：整体场景、重点细节、观察或参与动作；没有活动依据时只展示观察角度 |
| 质感 | 干净照片拼贴与短标注留白，统一边距，不自动生成地图 |
| 可替换字段 | 景点、文案主体、可用事实、目标人群、宣传目的、构图、比例、光线、人物、留白、处理强度方向 |

**研究依据与设计延伸**：按楼层、任务、工序和表达成果组织画面，转成可复用三格结构；不能把建议动作当成真实活动证明。

- [P13 · 中国动漫博物馆](https://www.rednote.com/discovery/item/69e18e98000000002200ec8d)：p1：童年IP拼图；p2–9：按楼层组织实景；p16：服务导览；借鉴：把多楼层内容拆成可浏览章节，而非堆成一张长攻略。
- [P16 · 湖北省博物馆手册](https://www.rednote.com/discovery/item/689ef240000000001b036ee4)：p1：手册在馆外实拍；p2：勾选地图；p3–4：文物标注卡；借鉴：把‘看什么’转成寻找、辨认、记录的具体动作。
- [P17 · 杭州非遗手作](https://www.rednote.com/discovery/item/6a2d4e590000000022014196)：p1：项目拼图；p4、p7：孩子亲手制作；借鉴：展示手、材料和半成品，比只拍空工位更能说明参与。
- [P19 · 阿嘟农场体验](https://www.rednote.com/discovery/item/69bfb5a80000000023015173)：p1–11：洗菜、拔萝卜、喂养、做饭等；p18：活动板；借鉴：按孩子实际动作排序；兑换奖励不能替代学习证据。
- [P20 · 科技馆小讲解员](https://www.rednote.com/discovery/item/6a92e8e200000000290353af)：p1：孩子讲解；p2：考核；p3–4：与观众交流；p5：准备；借鉴：以可观察的讲解行为收尾，不把个人成长写成普遍结果。

## 导师示例如何落到产品里

2026-10-27 导师示例可拆为：景区主体 + 水墨山景/纸感边框 + 前景人物 + 后期标题和“打卡”贴纸。
这是**参考照片编辑/人物合成**方向，不能承诺单靠景点名就能还原建筑或人物。

- 页面选择“水墨海报”即自动采用人文故事海报模板与水墨纸感；无需再选处理参数。
- 上传景区参考图用于约束真实结构；如要加入人物，另外上传人物参考图。
- 保留照片中主体的外形和身份特征，人物合成不等于曾经到访。
- 示例中的人物、奖杯、地标和文字不是自动添加到所有图片里的素材。本库不打包导师截图和人物照片。
- 本版仅记录参考图的尺寸、摘要和角色；素材只留在当前会话，不调用模型。
- 中文标题与印章不交给模型生成，先保留空白，后续人工排版。

## 底层选项怎样改变画面（开发资料）

界面只显示风格、主体、感觉和尺寸；以下参数由系统组合，不要求用户逐项设置。

| 输入 | 实际作用 |
|---|---|
| 景点/推广重点/文案 | 决定画面对象及与文案的对应关系，避免切换风格后换了景点 |
| 模板 | 切换单幅实景感、文化主视觉、三格体验组织 |
| 创作方式 | 区分无参考的概念设计与需要照片的结构保留编辑 |
| 画面主体 | 把注意力集中到一个具体、可见的景物或物件 |
| 比例 | 定义竖版、方形或横版构图；本版不裁切上传原图 |
| 取景 | 整体环境、局部特写、居中主体；拼贴中作用于主格 |
| 光线 | 自然柔光、夕照、阴天、夜景等创意设定；不推断真实天气或营业安排 |
| 色彩 | 明确背景与点缀色，保留主体本色 |
| 人物 | 不添加、少量远景、用户提供人物；缺少人物参考时不允许完成该方案 |
| 标题留白 | 预留上方或侧边空间，不生成乱码文字 |
| 风格化处理 | 模板默认、轻度、水墨纸感、剪贴手账 |

## 两个景点 × 三个模板对比准备

随附 `comparison_prompts_v1.json` 有乌镇西栅和杭州西湖共六份完整方案。
每个景点固定同一文案、主体、比例（3:4）、无新增人物、上方留白，仅切换模板。
预期差异是构图与表现语言，不是编造新的景点设施。六份是**待生成提示词**，不是已经完成的效果对比。

| 后续检查项 | 当前状态 | 通过标准 |
|---|---|---|
| 输入真正影响提示词 | 自动化与页面测试 | 每项改变对应指令，返回步骤/语言切换不丢选择 |
| 景点与文案一致 | 提示词层面可查 | 重点来自当前文案资料，不混入其他景点 |
| 地标/人物外观准确 | 未测试 | 将真实生成结果与可用原图逐项对照 |
| 三种风格可辨认 | 未测试 | 同一景点三图的主体相同，构图/表现可区分 |
| 文字与版式 | 未测试 | 后期文字清楚，不遮主体，不伪造现场标识 |
| 可复用性 | 已准备第二景点提示词；出图未测试 | 更换景点仍保持模板规则，不残留上一景点内容 |
